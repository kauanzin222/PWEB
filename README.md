# 🌐 Programação Web - Atividades e Projetos Acadêmicos

![Status](https://img.shields.io/badge/Status-Concluído-Green)

Este repositório foi criado para centralizar todos os meus estudos, anotações e projetos práticos desenvolvidos na disciplina de **Programação Web**. O foco desta matéria é o aprofundamento em tecnologias fundamentais para o ecossistema web, preparando-me para desafios complexos como **Desenvolvedor Full-Stack**.

## 🚀 Foco e Aprendizados

Ao longo das aulas, explorarei conceitos avançados que são pilares do desenvolvimento web moderno:

- 🎨 **CSS Avançado**: Estudo de layouts complexos, responsividade, animações e metodologias para estilização profissional.
- ⚡ **JavaScript (ES6+)**: Domínio de manipulação de DOM, programação assíncrona (Promises/Async-Await) e as novas funcionalidades da linguagem.
- 🟢 **Node.js**: Introdução ao desenvolvimento server-side, criação de APIs e gerenciamento de pacotes para construção de aplicações robustas.
- 🏗️ **Projetos Práticos**: Desenvolvimento de sites completos e aplicações web interativas como forma de consolidar o conhecimento teórico.

## 🛠️ Tecnologias e Ferramentas

Para a realização das atividades e projetos, utilizo:

- **Linguagens**: HTML5, CSS3 e JavaScript (ES6+).
- **Runtime**: Node.js para execução de JavaScript no servidor.
- **Editor**: Visual Studio Code com extensões focadas em produtividade web.

## 🎓 Contexto Acadêmico

Este repositório faz parte da grade curricular do curso de **Análise e Desenvolvimento de Sistemas** na **Fatec Sorocaba**. Ele serve como um portfólio de evolução técnica, documentando cada etapa do meu aprendizado em tecnologias web.
